      Tentang Proyek

      TiketKita adalah proyek akademik mata kuliah Struktur Data. Algoritma berjalan di backend C++, sedangkan halaman ini hanya menampilkan hasilnya.

      Array

      Menyimpan banyak tiket berurutan di memori. Elemen diakses dengan indeks.

      Tiket daftarTiket[MAKS_TIKET];
int jumlahTiket = 12;
daftarTiket[0]; // tiket pertama

      Struct

      Mengelompokkan data satu tiket dalam satu paket, sehingga satu tiket bisa dipindah atau ditukar sekaligus.

      struct Tiket {
    int id;
    std::string kode, maskapai;
    std::string asal, tujuan;
    int harga;
};

      Pointer

      Menyimpan alamat memori. & mengambil alamat, * mengambil isi, -> mengakses anggota struct lewat pointer.

      Tiket* p = daftarTiket;
p->harga;   // isi tiket yang ditunjuk
p++;         // pindah ke tiket berikutnya

      Sorting (Bubble Sort)

      Membandingkan dua elemen bersebelahan dan menukarnya jika urutannya salah. Terbaik O(n), terburuk O(n²), ruang O(1).

      if (kiri->harga > kanan->harga) {
    tukar(kiri, kanan);
}

      Searching (Linear Search)

      Memeriksa elemen satu per satu dari indeks 0. Teks dinormalisasi (huruf kecil, tanpa spasi tepi) agar tidak peka huruf besar/kecil.

      if (normalisasi(p->tujuan) == kunci) {
    hasil.push_back(p);
}

      Struct Produk (layanan lain)

      Kereta, mobil, hotel, vila, apartemen, aktivitas, dan paket memakai satu struct dan satu array. Algoritma bekerja pada daftar pointer ke elemen kategori tertentu.

      vector<Produk*> daftar =
    ambilProdukKategori("kereta");
tukarProduk(daftar[j], daftar[j + 1]);
